# Network Security

This module covers foundational network security concepts including service discovery,
protocol analysis, firewall policy review, and access-control bypass techniques.

## Challenges

| # | Challenge | Difficulty | Points | Skill |
|---|-----------|------------|-------:|-------|
| 1 | Port Authority | Easy | 50 | TCP port scanning & service interaction |
| 2 | Trust Boundary | Medium | 100 | Firewall ACL analysis & rule ordering |

## Skills You Will Practice

- Identifying listening TCP services on a target host
- Interacting with custom TCP diagnostic protocols
- Reading and reasoning about firewall ACL rule sets
- Spotting misapplied or misordered access-control rules
- Exploiting network segmentation misconfigurations

> All challenges are self-contained and run entirely within your workspace.
> No external network access is required.
