# Linux & General Skills

This module tests foundational Linux system administration, filesystem investigation,
text processing, and scheduled-job analysis skills in realistic operational environments.

## Challenges

| # | Challenge | Difficulty | Points | Focus |
|---|-----------|------------|-------:|-------|
| 1 | Dotfile Trail | Easy | 50 | Filesystem navigation, directory trees, hidden dotfiles |
| 2 | Midnight Maintenance | Medium | 100 | Cron configurations, script tracing, log correlation, compressed log analysis |

## Skills You Will Practice

- Navigating complex Linux directory hierarchies (`cd`, `pwd`, `ls -la`)
- Locating hidden files and dotfiles across nested structures (`find`, `grep`)
- Inspecting configuration and log files (`cat`, `head`, `tail`, `grep`)
- Correlating cron schedules, execution timestamps, and job IDs
- Tracing bash execution paths and environment configurations
- Analyzing compressed system logs and audit reports (`gzip`, `zcat`, `zgrep`)

All challenges are self-contained and run within your isolated workspace without requiring root privileges.
