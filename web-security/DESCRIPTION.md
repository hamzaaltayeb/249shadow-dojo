# Web Security

Welcome to the **Web Security** module for the 249shadow DOJO.

This module introduces fundamental web application security concepts, focusing on real-world vulnerabilities in modern web architectures. You will learn to analyze application workflows, inspect client-server communications, and identify flaws in authentication and authorization mechanisms.

## Challenges

- **Broken Records**: Investigate an internal personnel record archive and exploit an Insecure Direct Object Reference (IDOR) vulnerability to retrieve restricted intelligence.
